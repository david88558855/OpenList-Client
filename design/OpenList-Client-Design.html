05 — Layout & Function

布局与功能口径（统一基准）

本节是实现与验收的唯一口径：所有平台按此对齐布局与功能。尺寸以画板 CSS 为准，交互状态与代码一致。

A2 · 文件页
  • 顶栏：服务器芯片（点击直达服务器管理）+ 搜索 + 刷新。
  • 存储卡：152×96，整卡可点进入挂载点，副行为 已用 X · N%。
  • 筛选：全部 / 视频 / 图片 / 文档（不含音频）。
  • 面包屑：12.5px 逐级可点，跳转上级目录。
  • FAB：右下 58px，展开旋转 45°，菜单为新建文件夹 / 上传文件 / 离线下载。
A3 · 传输页
  • 分段标签：进行中 N / 已完成 N / 失败 N，选中为深色药丸 #0D1B2A。
  • 右侧「全部暂停 ›」：全局暂停 / 继续切换。
  • 任务卡：图标 + 名称 + 路由速度 + 百分比，进度条，底部 bytes / 剩余时间。
  • 刚刚完成：分区列出最近完成项，右侧「全部」跳已完成。
  • 开关卡：仅在 Wi-Fi 下传输 / 后台保持传输（前台服务），持久化。
A6 · 设置页
  • 分组：服务器管理 / 下载目录 / 存储挂载 / 我的分享。
  • 第二组：传输设置 / 播放与缓存 / 外观。
  • 第三组：隐私与安全 / 通知 / 关于 OpenList。
  • 下载目录：Android 先提示「所有文件访问」授权，再选目录。
A7 · 长按面板
  • 标题：已选择 N 个项目 + 取消。
  • 高频四动作：播放 / 下载 / 分享 / 收藏。
  • 次级列表：重命名 / 移动到… / 复制到… / 压缩下载（ZIP）/ 删除。
  • 删除：危险色 #D92D4B，行末 chevron。

06 — Decisions

已定项，设计冻结

命名、多服务器、管理后台、主题、Windows 发行与技术栈已确认并写入界面。

01
产品命名OpenList Client · 副标题区分 Windows / Android Edition
02
管理后台 · 只读仅存储健康 / 容量 / 版本；创建、用户、索引跳浏览器
03
多服务器 / 多账户数量不限；凭据、缓存、下载目录、浏览位置按服务器隔离
04
主题默认值跟随系统；播放器与全屏媒体强制深色
05
Windows 发行形态仅便携版 zip（OpenList-Client-<ver>-windows-x64-portable.zip），托盘常驻、关闭到托盘
06
技术栈Flutter 3.x + Riverpod + go_router + dio + media_kit；图标线性 SVG
设计基线锁定：未收到变更指令前不改交互与视觉口径。Windows 永久不提供安装包，设计稿与产物一致。
07 — Handoff

给实现的开工口径

技术栈

Flutter 3.x 单代码库；Riverpod 状态、go_router 路由、dio 网络、media_kit 播放、tray_manager 托盘。禁本地编译，编译只在 CI。

一致性验收

逐画板核对布局、间距、颜色、组件与交互状态；截图仅供参考，最终以布局与功能一致为准。设计稿随仓库提交但构建永不读取。

Windows 发行：仅便携 zip，解压即用；托盘常驻，右键「显示主界面 / 退出」，关闭一律收起，仅托盘「退出」结束进程。exe 图标与安卓启动图标同源。永久不提供安装包。
